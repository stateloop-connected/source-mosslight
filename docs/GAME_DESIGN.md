# 游戏设计 v1.0

## 核心循环

移动躲避 → 自动照亮虫影 → 拾取金色微光 → 暂停选择三选一能力 → 更密的虫影 → 存活至黎明或生命归零 → 结算、再来一局。

## 规则

| 项目 | 标准守夜 | 练习 |
| --- | --- | --- |
| 时长 | 180 秒 | 90 秒 |
| 基础生命 / 速度 | 100 / 175 世界单位每秒 | 相同 |
| 萤火基础伤害 / 间隔 | 16 / 0.66 秒 | 相同 |
| 敌人生成系数 | 1 | 0.65 |
| 接触伤害系数 | 1 | 0.55 |
| 巨蛾出现 | 140 秒 | 65 秒 |
| 巨蛾生命 | 750 | 420 |
| 正式手记 | 计入 | 不计入 |

地图 2000 × 1500 世界单位，摄像机跟随，边缘限制移动。攻击范围 520，子弹速度 460，冲刺基础冷却 3.8 秒，冲刺免伤 0.42 秒；普通受伤后免伤 0.85 秒。敌人在玩家 650 单位附近生成并保证距离至少 280，避免角落贴脸生成。

## 成长

第 L 级的升级需求为 `8 + L × 5` 经验；多余经验保留。最多展示三种未满级能力。每次升级只应用当前选择，所有能力都保存于本局 build，不跨局增强。

| 能力 | 效果 / 每级 | 上限 |
| --- | --- | --- |
| 炽热萤火 | 伤害 ×1.3 | 5 |
| 风铃草 | 射击间隔 ×0.82 | 5 |
| 双生花 | 额外 1 枚萤火 | 3 |
| 轻叶步 | 速度 ×1.16 | 3 |
| 引光苔 | 拾取吸引范围 ×1.5 | 3 |
| 晨露 | 上限 +20，回血 40 | 4 |
| 护身叶 | 每 0.55 秒造成 10 点额外近身伤害 | 4 |
| 夜行风 | 冲刺冷却 ×0.8，回血 15 | 3 |

## 敌人

- 灰紫小螨：基础追逐单位，2 经验。
- 青灰甲虫：更慢、更厚，4 经验，第 22 秒后加入。
- 淡紫飞影：更快、生命较低，3 经验，第 45 秒后加入。
- 噬光巨蛾：单次出现，40 经验。击败可加快后期成长，非获胜强制条件。

普通敌人的生命与速度随局内时间缓慢增加。屏幕实体与经验物体数量受限，避免长时间积累失控。

## 范围边界

没有多人联机、在线排行或跨局付费增强。当前数值为首版，需要真实玩家继续调优。练习的目标是让第一次接触此类型的玩家熟悉移动和拾取。
