## v1.1 规则模拟

用五个种子分别模拟桌面 / 手机可见场景、标准 / 练习的四种组合，共 20 次。策略拾取微光、选取成长能力、躲避近敌和使用冲刺，均能走到获胜。标准结束约 16–17 级、练习约 7–9 级。此测试用于发现规则卡死，**不构成游戏难度、趣味或真人胜率评估**。

## 复现

`npm ci` 后执行测试命令。Windows 会自动使用本机 Edge；Linux CI 使用 Playwright Chromium。截屏脚本需要先启动 `npm start`。不要同时启动多个浏览器截图任务，以免浏览器设备模拟设置互相影响。
