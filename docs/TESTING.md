## v1.1 规则模拟

## 复现

`npm ci` 后执行测试命令。Windows 会自动使用本机 Edge；Linux CI 使用 Playwright Chromium。截屏脚本需要先启动 `npm start`。不要同时启动多个浏览器截图任务，以免浏览器设备模拟设置互相影响。

## v1.1 检查范围

当前共 25 项逻辑 / 构建测试通过、23 项浏览器流程通过，3 项手机专用用例在桌面跳过。测试覆盖真实拾取初始微光升级、屏幕左侧触摸拖动、松手停止、320px HUD 布局、固定时间步进、存储失败与恢复、完整结算流程。构建后的静态站也独立验证了统一版本号、进入游戏、升级三选一、暂停，记录见 build-verification.json。

视觉扫描只有 68 条 design-system advisory，主要是原有画面分层色和局部字号未逐一列入机器令牌，不含警告或错误；此次沿用已有视觉世界，不做全局颜色/字号替换。视觉检查为本轮维护检查，独立检查记录 REVIEW.md 中的 ship 结论仍仅对应 1.0 两个修复。
