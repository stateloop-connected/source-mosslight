# 后续创作记录

## 下一轮先做什么

先收集 3–5 位真实玩家反馈：是否理解自动攻击与拾取、第一次升级花多久、手机摇杆是否舒适、标准局是否太轻或太难。记录设备、浏览器和具体操作，不仅记录“好玩 / 不好玩”。

## 优先验证

- 真实 iOS Safari、不同安卓设备与键盘浏览器。
- 低端设备的帧率、耗电和后期大量敌人。
- 按反馈调整生成距离、成长节奏、巨蛾压力与近身反馈。

## 再考虑的扩展

- 第二张地图与不同守夜人，先验证差异是否能改变玩法。
- 可复现的每日种子挑战，默认保持本地成绩。
- 游戏内图鉴和明确的能力组合说明。
- 在有需求后再评估离线安装能力，不提前增加后端。

同方向的新作品放在 `01-survival-roguelite/` 下的新子目录；当前游戏持续迭代直接修改本项目，保留版本历史和日志。
